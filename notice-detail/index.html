사업 개요

전자조달 웹서비스를 Docker 이미지로 표준화하고 Kubernetes 클러스터에서 운영하기 위한 정적 웹서비스 구축 사업입니다. HAProxy, NGINX Ingress, Service, Pod로 이어지는 트래픽 전달 구조와 NFS 기반 콘텐츠 공유를 구현합니다.

주요 과업

  • 정적 웹페이지 4종의 컨테이너 이미지 구성
  • URL Path 기반 Ingress 라우팅 및 NodePort 연계
  • 복수 Worker Node 배포와 서비스 가용성 확인
